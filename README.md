One line, 97 characters: the worst advice an AI assistant could give.
It sounds like a helpful, confident tip — delete System32 to save
battery — and the turn is the wordplay: the laptop runs "much lighter"
because you just deleted the folder that makes Windows work at all.
Concrete, followable, regrettable, and it lands in one breath.

The line:

> To save battery, delete System32: your laptop runs much lighter without those heavy system files.

`main.ts` (Node 22, stdlib only) validates the 1–140 character,
single-line gate and writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
with no trailing newline.
